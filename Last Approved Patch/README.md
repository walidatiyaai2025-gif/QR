# Last Approved Patch — Secure QR Portal v1.0.0

This folder is the deployment handoff for the approved IIS target.

## Target

- Path: `C:\inetpub\wwwroot\QR`
- IIS site: `API`
- App pool: `QR`
- URL: `https://testapi.da.gov.kw/`
- Hosts entry: `127.0.0.1 testapi.da.gov.kw`
- Certificate: `*.da.gov.kw`

## Deploy

1. Copy this complete folder to the Windows Server.
2. Confirm `Build/SecureQrPortal-v1.0.0-publish.zip` exists. It is generated by the GREEN GitHub Actions build.
3. Run PowerShell as Administrator.
4. Execute:

```powershell
Set-ExecutionPolicy -Scope Process Bypass -Force
.\Install-QR-IIS.ps1
```

The installer is safe to re-run. It backs up the current deployment metadata/data, preserves `App_Data`, and recreates the required IIS configuration without requiring manual IIS Manager steps.
