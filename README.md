# Secure QR Portal v1.0.0

Secure QR Portal is an ASP.NET Core MVC administration and secure-content portal for issuing cryptographically secure QR links, managing organizations and Secure Pages, auditing access, and centrally administering every QR code from **QR Management → QR Code Registry**.

## Platform

- .NET 10 LTS (`net10.0`)
- ASP.NET Core MVC + Razor Views
- ASP.NET Core Identity
- Entity Framework Core 10
- SQLite by default: `App_Data/SecureQrPortal.db`
- Microsoft SQL Server 2022 optional provider
- Arabic RTL and English LTR

## Quick start

```powershell
dotnet restore SecureQrPortal.sln
dotnet build SecureQrPortal.sln -c Release
dotnet test SecureQrPortal.sln -c Release
dotnet run --project src/SecureQrPortal/SecureQrPortal.csproj
```

A fresh SQLite database is initialized automatically. On the first visit, the system provides a one-time administrator setup flow. No production password is committed to source control.

## IIS approved deployment

The repository contains an approved deployment package folder:

`Last Approved Patch`

After GitHub Actions completes successfully it contains/produces:

- `Build/SecureQrPortal-v1.0.0-publish.zip` — IIS-ready Release publish output.
- `Install-QR-IIS.ps1` — idempotent Windows Server/IIS setup and deployment script.
- `BUILD-MANIFEST.json` — source SHA/build metadata generated by CI.

Default IIS deployment settings are:

- Physical path: `C:\inetpub\wwwroot\QR`
- IIS site name: `API`
- Application Pool: `QR`
- Host name: `testapi.da.gov.kw`
- Hosts mapping: `127.0.0.1 testapi.da.gov.kw`
- HTTPS certificate: `*.da.gov.kw`

Run PowerShell **as Administrator** from `Last Approved Patch`:

```powershell
Set-ExecutionPolicy -Scope Process Bypass -Force
.\Install-QR-IIS.ps1
```

The script installs IIS features and the .NET 10 ASP.NET Core Hosting Bundle when required, preserves existing `App_Data`, configures the application pool/site/bindings/ACLs/hosts file/firewall, binds the wildcard certificate, starts IIS, validates HTTPS, and opens `https://testapi.da.gov.kw/`.

## CI

`.github/workflows/ci.yml` performs restore, Release build, automated tests, publish packaging, source packaging, artifact upload, and refreshes the approved published build ZIP on the working/release branch after a successful push build.

## Security notes

- Public QR URLs use cryptographically secure random tokens; internal sequential QR references are never public authentication tokens.
- Secure Page passwords are hashed and never exported/displayed.
- Admin authentication is handled by ASP.NET Core Identity.
- Data Protection keys are stored under `App_Data/keys` for local operation; production deployments should protect and back up this directory.
- Production secrets and SQL Server credentials must be supplied through protected configuration/environment mechanisms and are not committed.
